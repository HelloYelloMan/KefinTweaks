# Fork audit — 2026-09-23, up to a3dcc59

An audit of everything this fork adds to or changes in upstream KefinTweaks. It
records what was reviewed and what was fixed, with the reasons, so a later reader
does not have to rebuild the reasoning.

## Method

- **Mechanical checks first.**
  - The two script registries (`injector.js` and `scripts/kefinTweaks-loader.js`)
    were compared by name.
  - The registries were checked for `,,` gaps.
  - `node --check` was run on every changed file.
  - The live web root was compared with HEAD using `cmp`.

  All passed at the start.
- **Six parallel read-only reviewers**, one per area:
  - player scripts
  - theme, cast and tags
  - card sizing
  - specials and series
  - loader and infrastructure
  - home screen and skins

  Each reported findings with a concrete failure scenario and a confidence level.
- **Every finding was checked against the code before anything was changed.** Only
  plainly obvious bugs were fixed on the spot. Anything that needed a browser test
  or a design decision went to Robert.
- **A follow-up reviewer** looked into ten candidate inefficiencies. It checked them
  against the jellyfin-web 10.11.11 source and the live server API, then produced
  patches.
- Fixes were deployed in checkpoints. Robert tested each checkpoint in his own
  browser before the next one.

## What the fork contains (inventory at 3ba8611)

**New features**
- **Pause Screen:** an overlay after 3s paused with the logo, plot, art, progress and "Ends at".
- **OSD Logo:** puts the item's logo or ClearArt on the player controls.
- **Theme Media Cast Fix:** a complete replacement for theme songs and videos that works while casting.
- **Cast Session Watchdog:** re-subscribes the Sessions feed when the now-playing bar goes stale.
- **Media Tags:** a Tags row on detail pages, plus a skin option to hide it.
- **Virtual Specials:** collection-page fixes, including borrowed art, the Studios row and single-item layout.
- **Special Episode Prefix:** strips Jellyfin's localised "Special - " from season-0 titles.
- **Episode Season Title:** the season title or logo on episode pages; a season's logo links to its series.
- **Poster Aspect**, and the older True Aspect Cards, which this audit removed.
- **Patches to other plugins:** `jeSidebarMemo` and `jeSpoilerGuardScope` for Jellyfin Enhanced; `elegantfin-haspatch` replaces ElegantFin's `:has()` selectors.
- **Skin options:**
  - Abyss colour schemes and an unblurred backdrop.
  - ElegantFin OLED and collection poster layout, and a local media-bar support sheet.
  - Global: Performance Mode, Center Library Cards, Hide Buttons On Library Cards, Hide Specials Season, Hide Media Tags, and the collection single-item layout.

**Changes to upstream files**
- **Loading:**
  - Cache tokens (`?v=<ETag>`) on the loader, `injector.js` and skin URLs.
  - Waiting for jellyfin-web to boot.
  - Game consoles are skipped.
  - Fork features are registered in both registries.
- **Home screen:**
  - Smart watched filtering.
  - SmartSimilar rows, plus Series versions of the People and Similar groups.
  - Spotlight pairing.
  - Numeric settings no longer revert as you type.
- **Infinite scroll and watchlist:** leaked listeners and polling were removed.
- **Series pages:**
  - The Flatten Single Season Shows crash is fixed.
  - The flat season row keeps the server's order.
- **Card path:** style-recalc reductions, and aspect ratios are requested in every home query.

## Fixed

Grouped by symptom. The commit hashes are the record; the diffs carry comments
explaining each change.

### Visibly broken before the audit

- **The watchlist button was hidden on every card** (`aef640b`).
  - The upstream merge `369897a` dropped the `kefin-has-playstate` class from
    `cardBuilder.js`.
  - `watchlist.css` still had `.card:not(.kefin-has-playstate) .watchlist-button
    {display:none}`, which then matched every card. Native cards never had the
    class anyway.
  - Fixed by deleting the rule; upstream never had it.
- **Nine Series discovery rows never rendered** (`62d20d6`). These were People Shows,
  Recently Watched People (Shows), Similar to Watched (Shows) and Liked (Shows).
  - They used the legacy `type: 'Person'|'Similar'` field.
  - The config migration rewrites `type` to `'discovery'`, so the sections resolved
    as misconfigured.
  - This is the same trap `799a936` fixed for SmartSimilar. Fixed by adding
    `discoveryType`.
- **Played cards still showed the watchlist button** (`9145cab`, `4357497`).
  - The rule `button[data-played] ~ .watchlist-button` can never match, because the
    watchlist button comes before the played button.
  - It is now `.watchlist-button:has(~ button[data-played="true"])`. The subject is
    the button itself, not every card, so it does not bring back the cost that
    `c58fabf` removed.
  - It hides with `visibility`, not `display`, so the neighbouring buttons do not
    move.
- **The ElegantFin media-bar watchlist icon was black on a dark backdrop**
  (`9145cab`).
  - `elegant-kefin.css` cleared only the background, not the colour.
  - It now uses `var(--textColor)`, as ElegantFin's own favourite button does.
- **4:3 episode stills were cropped to 16:9** in two places:
  - **Our own episode cards** (`9145cab`): they requested a fixed 474x267 crop.
    They now request the image at the still's own ratio.
  - **The episode page cover** (`2949e54`):
    - jellyfin-web treats any ratio of 1.33 or more as a backdrop cover (a 4:3
      still is 1.333) and fixes the box at 16:9.
    - Poster Aspect only had a width-led rule for portrait covers, and it excluded
      `.detailImageContainer` from its episode rules.
    - Fixed by mirroring the portrait rule for backdrop and square covers, keyed on
      the `par-NN` class alone.
- **Titles merely containing "Special - " were mangled** (`9145cab`).
  - "The Holiday Special - Part 1" became "The Holiday Part 1".
  - The pattern is now anchored to the start of the text or to Jellyfin's own
    `' - '` separator.

### Races on navigation

jellyfin-web keeps up to three views cached and hides inactive ones with `.hide`. An
earlier page can therefore come first in document order, and a slow fetch can
resolve after the next page's handler has started.

- **Stale OSD page in Pause Screen and OSD Logo** (`acfaae8`): lookups are now scoped
  to `#videoOsdPage:not(.hide)`.
- **Pause Screen re-showing itself** (`acfaae8`):
  - It re-showed on every mouse move, which overwrote the focus to restore on resume.
  - The logo's inline `display` survived a reset, so a failed fetch showed its alt
    text.
- **Theme Media** (`acfaae8`):
  - The between-items delay stopped the playback poll, so the next theme played over
    a movie.
  - Leaving for a page without theme media did not cancel an in-flight load.
- **A late fetch cancelling the next page's work** (`acfaae8`, `c69863a`): fixed in
  Media Tags, Episode Season Title and Virtual Specials.
- **Virtual Specials** (`c69863a`):
  - `alive()` only turned false when the next *details* page opened, so art retries
    repainted a borrowed backdrop onto Home.
  - Its lookups are now scoped to the page, and it observes the stable
    `.collectionItems` parent.

### Other bugs

- **Series pages:** a crash going back to a series with no Next Up card marked
  (`c69863a`).
- **Spotlight separation was silently undone** (`62d20d6`): it ran after `order` was
  stamped, and rendering sorts by `order`.
- **SmartSimilar limit doubled twice** (`62d20d6`): the guard tested `type`, which
  is always `'discovery'`.
- **Infinite-scroll letter filter ignored** (`62d20d6`): it only recognised
  `tv.html`/`movies.html`, not 10.11's `tv`/`movies`.
- **Config modal enabled features on save** (`8c56501`):
  - It showed default-off features as on when their key was unset:
    `trueAspectCards`, `posterAspect`, and upstream's `updoot`.
  - Any save then switched them on.
- **HEAD requests without a timeout** (`8c56501`): the `withCacheToken` requests in
  all three copies now time out after 3s. A stalled request held back the loader or
  a whole skin.
- **Abyss lost the green watchlist state** (`8c56501`): a (1,1,0) `!important` rule
  outranked the (0,2,0) one.
- **NeutralFin media-bar offset never applied** (`8c56501`): it matched only the
  upstream filename, not the default-on local `mediaBarSupport.css`.
- **ResizeObserver held detached rows** (`8c56501`): `publishHomeRowHeight` never
  unobserved the previous home row.
- **Console gate missing from the baked entry** (`90bf6b6`):
  - `KefinTweaks-injector` only checked `cfg.enabled`, so on a console every feature
    and skin still loaded.
  - It now makes the same user-agent check.
  - The stamp gained a generator version, `g2`, because the stamp alone decides
    whether the stored entry is rewritten.

### Removed

- **True Aspect Cards** (`4943965`):
  - Poster Aspect replaced it.
  - With both on, each measured probes sized by the other's CSS.
  - It left a permanent `fetch` wrapper and a 200ms scroll sweep.
  - Removed:
    - its script, stylesheet and settings page
    - both registry entries and its config toggle
    - `--kefin-card-ratio`, `data-kefin-ratio-set` and `data-ar`, which cardBuilder
      stamped only for it

    The `par-NN` class stays.
- **The Pause Screen backdrop layer** (`a3dcc59`):
  - It drew the item's own backdrop at 28% opacity, so films had art and episodes
    did not.
  - The blurred video frame alone is the intended look.

### Inefficiencies (`892682d`)

| Where | Was | Now |
|---|---|---|
| `seriesEpisodes` season-row check | `getComputedStyle` per season card on every mutation batch, for 5s on every series page (always the full 5s on multi-season shows) | once per animation frame |
| `posterAspect` | re-probed failing containers on every sweep (ElegantFin's hidden item-page cover on every item page); forced layout for containers inside `.hide` | failure remembered per skin, width, shape, picker and gap, and cleared by `invalidate()`; `.hide` skipped without layout |
| `osdLogo`, `pauseScreen` logos | HEAD or `onerror` probing of season, then series: 1-3 failed requests per item, untagged so uncacheable | the server-resolved `ParentLogoItemId`/`ParentLogoImageTag`: no probes, and a tagged URL caches for a year |
| `pauseScreen` disc and art | up to 3 failed requests per pause | one `Ids=` lookup for the parents' `ImageTags`, then requests by tag (the server never fills `ParentArt*`, and disc has no parent field) |
| `sectionHelper` smart rows | two UserData refreshes per cached smart or hide-watched row | the filtered result is reused when `ensureData()` returns the same payload |
| `themeMediaCastFix` | a body-wide subtree observer for the whole session when nothing played through the bar; header layout read on every inner-row scroll | observes only `body` and `.appfooter`; listens to document scroll only |
| `specialEpisodePrefix` | swept on the OSD clock's ~0.7s text rewrites, scanned every cached page, and re-asked about known non-specials | element insertions only, the visible page plus dialogs, and a permanent not-special set |
| `osdLogo` item observer | `childList` subtree, firing every ~0.7s during playback | `data-id` attribute only |
| `castSessionWatchdog` | parsed every WebSocket frame a second time | a text test |

Also: a theme item that fails mid-stream now advances to the next one instead of
leaving a dead element on screen.

Judged not worth changing:
- Theme Media's 250ms poll: its layout read happens at most once per theme.
- Failure caching in Episode Season Title and Virtual Specials: not a hot path.

## Traps worth remembering

- **A merge can drop a fork line that fork CSS still depends on.** After an upstream
  merge, grep the JS for a setter for every `kefin-*` class the fork's CSS selects on.
- **The discovery-section schema trap came back.** After adding sections, this must
  return nothing:

  ```
  grep -n "type: '\(Person\|Similar\|Genre\|Studio\)'," scripts/homeScreenConfig2.js
  ```
- **Do not key a cache on `<html lang>`.** jellyfin-web sets it after feature scripts
  first run, so the load and the save used different keys. A change made during this
  audit did exactly that; it was reverted in `4357497`.
- **Feature stylesheets and scripts carry no cache token.** Only the loader,
  `injector.js` and skin URLs do. After a CSS deploy, check that the browser has the
  new rules before debugging, for example by searching `document.styleSheets`.
- **Check the feature is enabled in the live config before debugging it.**
  `specialEpisodePrefix` was `false` on the server, which was the real reason
  "Special - Hell's Kitchen" survived on episode pages.
- **Changing `buildInjectorScript` output means bumping the `g2` generator version in
  the stamp.** Otherwise existing installs keep the old stored script.
- **Verify DOM questions in Robert's browser.** The episode-cover cause was found
  from his console output. It could not have been found from the code, because the
  row that looked like the suspect was already correct.
